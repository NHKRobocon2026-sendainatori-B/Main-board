# Main-board

## 概要
NHKロボコン2026のメインボードプログラムです。stm32f407VGT6を使ってます。

## 開発環境
STM32CubeIDE(1.19.0)

## フォルダ構成
```txt
├── Core
│　　 ├── Inc
│　　 │　　├── component : モーターなど、部品ごとのプログラム
│　　 │　　└── mechanism : 足回りなど、機構ごとのプログラム
│　　 └── Src
│　　  　　└── main.cpp
├── Drivers
└── Scripts : CubeMXによるジェネレートの際、C++で動かす際に使用したスクリプトファイル
```

## 使用しているクラスについて
使用しているクラスは全て自作してます。地区大会ではうまくいきましたが、これからも問題なく動くかはまだ確認してません。あくまで参考に。これから今回作成したクラスをもとにライブラリを作りたい考えてます。
